# Звук двигателей — 2026-11-03

## Что изменено

`EngineVoice` заменяет прежний почти чистый синусоидальный тон: низкий реакторный
гул, несколько полос отфильтрованной турбулентности, слабые резонансы турбины,
отдельная фактура форсажа, круиза, маневровых двигателей и тормозной тяги.
Громкость/фактура определяются тягой и режимами, не скоростью корабля.
Раскручивание около 0,45 с, спад тяги около 1,1 с; управление применяется
плавно на каждом аудиосэмпле. Прежние писки при включении/выключении тяги
и начале торможения удалены. Звук не запускает механику на сервере.

В меню до подключения, при докинге и потере соединения двигатель затихает.
`ShipAudio` остаётся единственным владельцем потока для F1/F2/F3. Форсаж
отделён от круиза; удержание Shift без тяги не создаёт полный рокот форсажа.
Сохраняется шина Engines и её существующий регулятор громкости. Музыка,
радио, навигационный сигнал, звук варпа и ударов используют прежние источники.

Процедурный стереосинтез 22 050 Гц, без внешних ассетов/зависимостей. Рабочий
буфер Vector2[256] используется повторно. Поток сохраняет запас 150 мс и
предварительно заполняется; укороченный до 80 мс буфер дал пропуски в headless
проверке, поэтому в итоговый вариант не вошёл.

## Пример для прослушивания

[engine_sequence.wav](media/engines/engine_sequence.wav), 28 с, stereo PCM16 / 22 050 Гц.
Это вывод того же `EngineVoice`, который работает в игре, до настроек громкости
и смешивания с музыкой/варпом. Пример не является статическим игровым лупом.

| Время | Режим |
| --- | --- |
| 0–1 с | выключен |
| 1–3 с | холостой ход |
| 3–7 с | тяга |
| 7–11 с | форсаж |
| 11–15 с | круиз |
| 15–18 с | обратная тяга |
| 18–20 с | маневровые |
| 20–22 с | торможение |
| 22–26 с | затухание до холостого хода |
| 26–28 с | отключение при докинге |

## Проверки

```bash
dotnet build client/IndifferentStars.Client.csproj --no-restore
godot-dotnet --headless --path client --editor --import --quit
godot-dotnet --headless --path client res://tests/EngineAudioChecks.tscn
```

Сборка — 0 предупреждений/ошибок, импорт — PASS. Проверки клиентского C#-синтеза
выполнены сценой Godot (вместо серверного dotnet test: серверные правила/DTO
не менялись). Сэмплы конечны, запас до перегрузки сохранён, устойчивого DC нет,
слои тяги/форсажа различаются, после снятия тяги звук затихает, маневровые
имеют стереоширину. Пик 0,3692 (−8,65 dBFS), максимальная разность соседних
сэмплов 0,1519. RMS: холостой 0,00289, тяга 0,04806, форсаж 0,08707,
круиз 0,05734. Выключенное состояние/конец докинга — тишина.
Headless-прогон: 0 пропусков потока после старта, остановка без утечек.

Живой клиент Forward+ / RX 580 с отдельным UDP-сервером:

```bash
dotnet run --project src/IndifferentStars.Server -- --bind 127.0.0.1 --port 17878
```

После сборки клиента, в другом терминале:

```bash
XDG_DATA_HOME=/tmp/is-engine-flight IS_SERVER=127.0.0.1:17878 \
 IS_ENGINE_FLIGHT=1 IS_ENGINE_CAPTURE=/tmp/indifferent-engines \
 godot-dotnet --path client --resolution 1280x720 res://tests/EngineAudioChecks.tscn
```

PASS. Сцена захватывает **настоящую шину Engines** через AudioEffectCapture:
тишина в главном меню; после подключения и клавиш S/Shift RMS 0,00300 на
холостом, 0,04723 на обратной тяге и 0,08298 на форсаже. Тяга подтверждается
серверным snapshot. Один звуковой узел сохраняется в F1/F2/F3, поток и выход
завершаются штатно. В оконном прогоне стартовый счётчик пропусков был 4,
после прогрева новых пропусков не появилось (4 → 4); во время этих стартовых
сэмплов двигатель неактивен. В логе нет ERROR/SCRIPT ERROR.

Параметры потока/запас уровней подтверждены технически. Художественная оценка
тембра и баланса с музыкой остаётся за прослушиванием владельца; это не измерение
«реалистичности» и не полный аудиомикс игры.
