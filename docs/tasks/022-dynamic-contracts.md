# 022 — Динамические контракты

[Журнал и порядок выполнения](../AUTONOMOUS_PROGRESS.md)

Создать систему контрактов, формируемых из состояния мира.

Начальные категории:

- перевозка грузов;
- снабжение станции;
- доставка дефицитного товара;
- добыча ресурсов;
- разведка;
- исследование сигналов;
- сопровождение;
- помощь кораблю;
- уничтожение подтверждённого противника;
- поиск и возвращение утраченного груза.

Контракты могут исполняться игроками и NPC.

Контракт должен иметь реальные условия, заказчика, вознаграждение, срок и проверяемый результат.

Не выдавать задание на доставку несуществующего груза или уничтожение несуществующего корабля.

Если потребность уже удовлетворена другим участником, состояние контракта должно корректно измениться.

Вознаграждение выдаёт сервер после проверки результата.

Поддержать принятие, отказ, завершение и провал контракта.

Состояние контрактов сохраняется.

Не создавать обязательную сюжетную кампанию.
