# 024 — Комплексная игровая приёмка

[Журнал и порядок выполнения](../AUTONOMOUS_PROGRESS.md)

После реализации предыдущих этапов провести комплексный аудит проекта.

## Игровой сценарий

Игрок должен иметь возможность:

1. Начать игру на небольшом курьере.
2. Ознакомиться с окружающим миром.
3. Найти возможность заработка.
4. Заработать первые кредиты.
5. Купить оборудование.
6. Выбрать профессию.
7. Столкнуться с реальной опасностью.
8. Избежать боя или вступить в него.
9. Отремонтировать корабль.
10. Накопить на другой корпус.
11. Продолжить развитие.
12. Посетить другую систему.
13. Выйти из игры и вернуться без потери прогресса.

По возможности реализовать автоматизированного игрового клиента, использующего штатный сетевой протокол и реальные игровые действия.

Не подменять проверку прямой установкой игровых состояний.

Провести отдельные сценарии для торговли, добычи, исследований, боевых действий и взаимодействия с другими игроками.

## Интерфейс

Проверить:

- удобство навигации;
- читаемость HUD;
- понятность сенсорных контактов;
- интерфейс торговли;
- верфи;
- оснащение кораблей;
- боевой интерфейс;
- журнал событий;
- контракты;
- настройки;
- локализацию;
- работу при разных разрешениях экрана.

Не допускать наложения панелей, нечитаемых элементов и функциональности, недоступной в отдельных представлениях.

## Баланс

Проверить время первых заработков, доступность новых кораблей, ценность разных профессий, риски торговли, частоту столкновений с противниками и стоимость ремонта.

Не допускать ситуации, когда один способ заработка делает все остальные бессмысленными.

Не превращать игру в чрезмерно продолжительный обязательный гринд.

## Атмосфера

Проверить визуальное разнообразие кораблей, станций, районов и систем.

Добавить недостающие звуки и эффекты, если это необходимо для восприятия уже реализованных механик.

Не использовать чужие ассеты с неизвестными лицензиями.
