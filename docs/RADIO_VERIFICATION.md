# Радиоэфир — 007

Чат реализован. Результаты проверок приведены ниже.

## Реализация

Внизу слева — три вкладки: «Локальный», «Система», «Общий».
История до 100 строк на канал, прокрутка без принудительного прыжка вниз при новых
сообщениях, счётчики непрочитанного. Текст пользователей показывается буквально,
включая скобки разметки. NPC/станция выделены цветом; повтор имени из старого
текста ответа удаляется, реплики больше не теряются в toast.

Enter открывает ввод и отправляет, Escape возвращает полёт. Ввод не включает
двигатели и не меняет ориентацию; вкладки не перехватывают клавиши полёта.
Чат остаётся во всех F1/F2/F3. Круиз сохраняется при наборе текста, меню настроек
обрабатывает ввод раньше игрового чата. Панель сканера поднята выше радиоэфира.

Local — 15 км в полном 3D. System/General — система/сервер; в текущем M0
единственная система, аудитории совпадают. Автор и время назначаются сервером.
Отправка/доставка имеют id, подтверждения и ограниченные повторы; дубли не
создают вторую строку или новую публикацию. Пустой текст, переносы/управляющие
символы, неизвестный канал и превышение двух сообщений/с отклоняются явно.

## Ограничения

История пока только в памяти клиентского сеанса. Нет долговременной очереди,
истории до подключения или гарантии доставки отключённому собеседнику.
Ожидание/повторы ограничены 4 с, очереди ограничены по размеру.

Создание пользовательских каналов и выбор участников/NPC оставлены на следующий
этап, как запрошено «потом». ChannelId и SenderId уже независимы от вкладки;
текущие три канала публичные. Идентификатор отправителя сохраняется и в истории
ответов NPC. Локальный фильтр интерфейса не выдаётся за приватную
серверную группу. Новые аккаунты, облачные API, БД и зависимости не добавлены.

Протокол **v15**: обновлять и перезапускать оба процесса.

## Воспроизведение

```bash
tools/run-local.sh
# Во втором терминале:
tools/run-client.sh --name Wingmate
```

Enter → сообщение → Enter, переключение вкладок мышью, Escape из строки.
Контекстное меню NPC → связь: ответ остаётся в «Локальном».
Настройка «Подсказки управления в HUD» позволяет убрать справочную панель над чатом.

Автоматическая проверка:

```bash
GODOT_BIN="$GODOT_BIN" tools/tests/check-surfaces-and-warp.sh
```

`RadioChecks` использует реальный GameMain и второй NetworkClient: доставка трёх
каналов, NPC, непрочитанное, буквальная разметка, дубликаты, ввод/выход, F1/F2/F3,
ограничение истории и сохранение прокрутки. Тест сервера проверяет два UDP-клиента,
повтор запроса без новой публикации, повтор доставки без ACK, rate limit и отказы.
Unit-тест аудитории проверяет 15 км по оси Y и отказ неизвестному каналу.

## Проверки на Linux, 2026-11-03

Release-сборка сервера/shared/simulation и Debug-сборка клиента — без ошибок
и предупреждений. Полный `dotnet test -c Release --no-build`: **134/134**, без
пропусков, 1 мин 16 с. Включены два UDP-клиента, повтор запроса/доставки,
ограничение частоты, серверные отказы, 3D-граница локального эфира, UTF-8 бюджет
и round-trip четырёх сообщений протокола.

Godot 4.7.2 .NET, Forward+, Radeon RX 580 2048SP 8 GB (RADV), Xeon E5-2680 v4,
1600×900, scale 1, MSAA 2×. Native `RadioChecks` использует настоящий GameMain
и второй сетевой клиент. Проверены Tab для выбора цели, Alt → Enter → выход из
ввода с восстановлением режима мыши, отсутствие тяги/поворота при наборе,
доставка трёх каналов, история NPC с SenderId, буквальная разметка, подавление
дубликатов, непрочитанное, F1/F2/F3, возврат полётного ввода, предел истории
100 строк и сохранение ручной прокрутки. Воспроизведение звука проверяется с
аудиодрайвером Dummy; субъективная оценка остаётся за владельцем.

Отдельно устранено зависание при завершении клиента: звук удара останавливается
перед выходом, новые голоса больше не создаются, потоки освобождаются при удалении
узлов. Native-прогон с verbose завершился с кодом 0 без утечек ObjectDB.

Полный пользовательский случай «после отказа сканирования корабль совсем не
двигается» независимо не воспроизведён. Подтверждены и исправлены длительное
уведомление, обработка повторов/таймаута; движение после успеха, отказа и удара
проверяется отдельными native-сценами. Это не утверждение о воспроизведении
всех возможных причин исходного зависания.

Итоговый `tools/tests/check-surfaces-and-warp.sh` завершён с кодом **0**:
Blender-проверка оболочек, Godot import, SurfaceGeometry/ShipTrack/Effects/Navigation,
SurfaceFlight, Warp, Camera, Impact, ScanRecovery и Radio. Удар подтверждён обоими
клиентами: 76,38 м/с по нормали, 21,51 м/с по касательной; после него возможен отлёт.

В окне измерения варпа — 607 кадров, p95 18,43 мс. В двух последовательных
5-секундных окнах статической F2-сцены радиоэфира — по 300 кадров:
панель скрыта p95 21,309 мс, показана 23,960 мс. Это короткие наблюдения с
работающим сервером и двумя клиентами, не оценка предельной нагрузки или
гарантия постоянного FPS. [Сводка прогона](performance/radio-2026-11-03/verification.txt).
