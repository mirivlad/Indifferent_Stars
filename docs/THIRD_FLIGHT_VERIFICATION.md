# Проверка оболочек и единого варпа — 2026-11-02

Задание: [003-surfaces-and-warp](tasks/003-surfaces-and-warp.md).
Ветка реализации: feat/surface-collisions-unified-warp.
Это инженерная проверка; художественная приёмка владельцем остаётся открытой.

## Воспроизводимый прогон

Укажите установленный Blender через BLENDER_BIN и Godot .NET через GODOT_BIN, если
их нет в PATH, затем выполните:

```bash
tools/tests/check-surfaces-and-warp.sh
```

Скрипт проверяет воспроизводимость поверхностей, при заданном BLENDER_BIN импортирует
GLB в Blender для независимого сравнения, собирает .NET/клиент, запускает тесты,
Godot import, headless-сцены и два графических сценария. Графика требует работающего
Vulkan-дисплея; звук проверяется с Dummy. Он запускает собственный сервер на UDP 17893
(IS_TEST_PORT меняет порт), проверяет успешный bind и завершает именно этот процесс.
Логи и кадры сохраняются в напечатанном временном каталоге; IS_CHECK_DIR задаёт другой.

- Godot: сопоставлены все треугольники корабля, станции и трёх астероидов

- SurfaceFlightChecks: реальное ядро GameWorld пропускает корпус через отверстие кольца

  нет ошибок рендера/извлечения frustum.
- WarpChecks: свободная точка из меню 2D, подтверждённый сервером маршрут,
  подготовка/перелёт/выход, все три представления, сразу второй прыжок к планете,
  затем перелёт к звезде на масштабе 1 а.е. Без круиза, локального лимита и cooldown.
  Прибытие сохраняет километр для всего корпуса, скорость нулевая. FOV ограничен,
  корабль и камера остаются в малом кадре координат на протяжении AU-перехода.
- Два независимых UDP-клиента: наблюдение стыковки, столкновения, фаз варпа и
  завершённого прибытия. Дубликат запроса не перезапускает варп; устаревший запрос
  отклоняется. Проверен отказ при несовпадении геометрии.
- Автотесты: вращение корпуса у препятствия, попадание концом крыла, проход рядом
  без сферической стены, высокая скорость, поверхность планеты/звезды,
  неизвестная цель, неверные координаты, занятая точка, отмена подготовки и
  безопасный возврат при занятии точки во время перелёта.
- Контрольная точка NPC Long Cargo перенесена из центра станции к его внешней
  точке маршрута; NPC не должен пытаться достичь точки внутри твёрдого корпуса.

## Ограничения

Вращательные контакты используют консервативную погрешность до 5 см; окончательный
контакт идёт по поверхности, не по объёмной сфере. Удара с повреждениями, упругих
отскоков, полноценного решения импульсов твёрдых тел и обхода препятствий нет.

Небесные тела имеют физическую сферическую поверхность, но их изображение остаётся
проекцией. Звезда сохраняет ограниченную художественную проекцию и вблизи, чтобы
frustum с миллиардными расстояниями не разрушал float-отсечение локального корабля. Это не меняет
координаты, сенсорную дистанцию и физическую коллизию.

Эффект варпа оригинальный процедурный; субъективное звучание и художественное
сходство с желаемым ощущением требуют игры владельца. Старые неподтверждённые
артефакты планеты не объявляются исправленными.

Задания 004 (станция) и 005 (корабль) записаны отдельно; новые детальные модели
в этой работе не изготавливались.
