# Пираты, патрули и торговые маршруты

Пары рейдеров Shrike и Scavenger появляются при создании системы.
Для каждого её сида укрытия и точки патруля определяются у добывающих
станций и грузовых узлов. Рейдеры летают с выключенным транспондером.
Они выбирают цели в области наблюдения. Размер трюма показывает
потенциальную ценность цели. Прочность корпуса, расстояние и число
ближайших патрулей влияют на готовность атаковать.

Рейдер возвращается при серьёзном повреждении или после захвата груза
из обломков. Содержимое обломков и трофеи меняются одной серверной
операцией. Захваченные припасы пополняют ограниченный запас укрытия.
Этот же запас уходит на восстановление корпуса, вооружения и
постройку резервного корабля.

Гражданский экипаж сообщает об обнаружении судна без транспондера,
пересматривает маршрут, запрашивает помощь при попадании и пользуется
обычным варпом, когда есть свободный участок для запуска. Патруль
реагирует на реальный сигнал из своего района и летит к цели обычным
ходом. Свободный патруль может выйти на сопровождение грузового корабля.
Корабль, напавший на мирную цель, на 150 секунд становится целью для
сил безопасности.

Зоны безопасности распределены по назначению станций, подходам к ним и
районам пиратских укрытий. В охраняемых торговых районах рейдеры
избегают нападений. Лазеры, коллизии и повреждения действуют там по
обычным правилам.

Торговый узел продаёт руду за 48 кредитов. Научная станция покупает её
за 54. Промышленная станция покупает медикаменты за 81 кредит при цене
65 на торговом узле. Грузовые узлы доплачивают за топливо. Цены видны
в станционном интерфейсе, сделку рассчитывает сервер.

## Резервные корабли

Погибший NPC оставляет обломки. После задержки от 105 секунд станция
может выпустить замену из восьми компонентов своего склада. Укрытие
ждёт от 180 секунд и тратит двенадцать единиц припасов. Каждая мастерская
выпускает не больше одного корпуса за 55 секунд.
Резерв занимает существующее место в населении, получает новый позывной
и выходит из района станции или укрытия. Недостаток ресурсов задерживает
выпуск. Пока в игре действует упрощённое производство корпуса с фиксированной
рецептурой.

Формат v4 сохраняет враждебность, припасы и сроки восполнения
потерь. В мирах v1–v3 продолжают существовать прежние NPC и добавляются
рейдеры из сида системы. В протоколе v26 опознанные сенсорные контакты
передают фракцию и отношение конкретного наблюдателя, а станции передают
фактические цены покупки и продажи.

## Как воспроизвести

```sh
dotnet build
dotnet test
dotnet build client
godot-dotnet --headless --path client --editor --import
dotnet run --project tools/IndifferentStars.Diagnostics -c Release -- --life 72000 20261101 0
dotnet run --project tools/IndifferentStars.Diagnostics -c Release -- --life 12000 20261101 3
```

Для проверки двух клиентов запустите
`tools/run-server.sh --bind 127.0.0.1 --port 17896`. Затем запустите
Godot с отдельным временным профилем.

```sh
run=$(mktemp -d)
mkdir -p "$run"/{data,config,cache,capture}
XDG_DATA_HOME="$run/data" XDG_CONFIG_HOME="$run/config" XDG_CACHE_HOME="$run/cache" \
  IS_SERVER=127.0.0.1:17896 IS_SECURITY_CAPTURE="$run/capture" \
  godot-dotnet --path client --resolution 1280x720 --audio-driver Dummy res://tests/SecurityChecks.tscn
```

Оба клиента выходят от станции на тяге и по обычным правилам варпа
переходят в район укрытия. До вылета рейдер отсутствует в опознанных
контактах. После прибытия клиенты получают один и тот же враждебный
контакт без транспондера и раскрытого назначения. На тактической карте
рейдер отмечен красным.

## Результаты

Все 236 тестов .NET прошли. Сборки решения и клиента завершились без
предупреждений. Импорт Godot в headless-режиме завершился с кодом 0.

Тесты подтвердили атаку на грузовой NPC и игрока, реакцию патруля на
попадание, обход охраняемой зоны, перенос трофеев из обломков,
восстановление у укрытия и оплату резерва со склада станции.
Два UDP-клиента получили разные отношения патруля к нападавшему и
жертве. Проверено чтение мира v3 и повторное чтение сохранённого состояния
v4 с расходом припасов, преступлением и таймером восполнения.

Прогоны без игроков выполнены в Release на Xeon E5-2680 v4, сид 20261101,
серверный шаг 50 мс.
